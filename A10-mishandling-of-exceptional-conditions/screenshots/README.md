# Screenshots: Mishandling of Exceptional Conditions

This directory stores original screenshots and visual evidence collected while completing hands-on labs for **A10:2025 – Mishandling of Exceptional Conditions**.

## Usage Instructions

1. **Save Screenshots Here:** Place your captured images inside this directory with descriptive filenames (e.g., `lab-01-idor-request.png`, `lab-02-bypass-success.png`).
2. **Reference in Write-ups:** Link each image from its corresponding lab write-up in `../labs/` using relative markdown syntax:
   ```markdown
   ![Request Inspection](../screenshots/lab-01-idor-request.png)
   ```
3. **Authenticity:** Only store genuine screenshots from your own active testing.
